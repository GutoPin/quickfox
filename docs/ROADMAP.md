# Roadmap

## Done

- [x] Native Rust binary with embedded English word lists; works offline.
- [x] Onboarding, typing, pause, results and safe terminal restore.
- [x] Campaign of five levels and fifteen missions; unrestricted quick play.
- [x] Adaptive word choice, XP, statistics, atomic saves, recovery and export.
- [x] Daily UTC challenge and focused practice with an error heatmap.
- [x] Navigation menu, command palette, resumable sessions.
- [x] 14 themes, editable JSON config with schema, live reload, custom keybindings.
- [x] Optional key sounds on Linux, synthesized or recorded.
- [x] Responsive layouts from 60×20 to 240×70, deterministic UI snapshots.
- [x] Formatting, Clippy, unit and integration tests, PTY smoke tests, CI.

## Before the first public release

- [x] Choose a license (MIT).
- [ ] Run the macOS and Windows CI jobs and try both by hand.
- [ ] Manual checks in GNOME Terminal, Kitty, WezTerm and over SSH.
- [ ] Watch five beginners use it and fix what trips them up.
- [ ] Publish a GitHub release with notes and checksums.

## Later

- [ ] Audio on macOS and Windows.
- [ ] cargo-dist installers and an npm wrapper for the native binary.
- [ ] musl and ARM builds.
- [ ] Imported text, ghost races against your own runs, achievements.
- [ ] Word lists in other languages.
- [ ] Screen-reader review.

Online accounts, leaderboards and multiplayer are out of scope: Quickfox stays offline.
